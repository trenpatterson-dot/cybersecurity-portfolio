# Detection Results

## Software Discovery using Powershell

Validated that defensive monitoring could identify PowerShell-based software discovery activity that may indicate attacker reconnaissance or environment profiling.

## Whoami Process Activity

Validated that the environment could detect user or account discovery behavior that helps analysts spot early-stage host enumeration.

## Windows Network Enumeration

Validated that command-line network discovery behavior was visible to defenders and could support investigation into lateral movement preparation.

## Enumeration of Administrator Accounts

Validated that privileged account discovery generated useful detection coverage tied to role and permission awareness activity.

## Potential Credential Access via Windows Utilities

Validated that the environment could detect credential-access behavior involving Windows utilities associated with LSASS memory targeting.

From a SOC perspective, these detections matter because they help surface attacker discovery and credential-access patterns before an intrusion progresses further.
