# Codex Start Here

Before starting work in this repo:

1. Read `AGENTS.md`.
2. Identify the task type before making changes.
3. Use the matching workflow or skill under `.agents\skills\` if available.
4. Confirm safety rules before editing files, staging changes, or suggesting Git actions.
5. Use CMD-style commands when giving Windows commands unless the task clearly requires another shell.
6. Do not invent evidence, screenshots, findings, or results.
7. Do not push to GitHub without approval.
8. Do not expose private lab data, personal data, secrets, credentials, or unpublished evidence.
9. For screenshots, use base filenames without file extensions unless the user asks otherwise.
10. For lab or project evidence, explain:
    - whether the screenshot is usable
    - where it belongs
    - why it matters
11. End lab, project, and GitHub tasks with both:
    - `CHATGPT HANDOFF`
    - `AGENT ROUTING RECOMMENDATION`
