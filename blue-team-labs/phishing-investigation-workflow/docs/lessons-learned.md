# Lessons Learned

## Key Lessons From This Investigation

This project provided hands-on experience with phishing investigation workflows commonly performed by SOC analysts.

The investigation focused on:
- phishing identification
- suspicious domain analysis
- social engineering indicators
- IOC extraction
- MITRE ATT&CK mapping
- defensive analysis documentation

---

# Phishing Indicators Are Often Layered

The phishing sample combined several suspicious behaviors:
- typosquatting
- reply-to mismatch
- urgency-based language
- suspicious verification links
- impersonation of a trusted organization

This demonstrated how phishing campaigns often rely on multiple overlapping deception techniques.

---

# Social Engineering Remains Highly Effective

The email used:
- password expiration warnings
- account suspension threats
- urgency-driven messaging

to pressure users into bypassing normal security awareness behaviors.

This reinforced the importance of user awareness training and phishing detection workflows.

---

# IOC Documentation Is Critical

Extracting and documenting indicators such as:
- domains
- URLs
- sender addresses
- reply-to infrastructure

helps defenders:
- block malicious activity
- improve email filtering
- enrich threat intelligence
- support future investigations

---

# MITRE ATT&CK Improves Investigation Context

Mapping the phishing behaviors to MITRE ATT&CK techniques improved understanding of:
- attacker objectives
- phishing tactics
- infrastructure abuse
- impersonation behavior

This also helped structure the investigation using industry-standard threat terminology.

---

# Documentation Quality Matters

The project reinforced the importance of:
- organized evidence
- screenshots
- investigation notes
- clear findings
- plain-language explanations

Strong documentation improves:
- SOC communication
- incident handoffs
- recruiter visibility
- portfolio quality
