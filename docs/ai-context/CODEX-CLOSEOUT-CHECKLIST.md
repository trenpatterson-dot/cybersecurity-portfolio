NOTION UPDATE:
For completed lab/project outputs, include a copy/paste-ready `Notion Update` section using `docs\ai-context\NOTION-PORTFOLIO-COMMAND-CENTER.md`.

Required fields:
- Project/Lab Name
- Category
- Status
- Platform
- Tools Used
- Skills Demonstrated
- Evidence/Screenshot Folder
- GitHub README Status
- LinkedIn Draft Status
- Supervisor-Agent Handoff Status
- Security Review Status
- Date Started
- Date Completed
- Priority
- Notes

Use these closeout rules:
- For GitHub decisions, default to `github-safety`, `cyber-lab-workflow`, and `tren-writing-voice` when those workflows are available.
- Do not recommend local agents for GitHub safety decisions unless the user explicitly asks for them.
- Do not run local agents unless approved.
- Do not use `git add`, commit, or push unless explicitly approved.
- Use this status flow for portfolio tracking: `Idea -> In Progress -> Needs Evidence -> Needs README -> Needs Security Review -> GitHub Ready -> Published`.
- No project is fully complete until evidence/screenshots are validated, README is complete, security review is complete, supervisor-agent handoff is complete, and GitHub publishing status is clear.
- Keep LinkedIn drafts local-only. Do not add LinkedIn draft files to GitHub publishing guidance.
- Do not connect to Notion or require a Notion API integration for closeout. Provide copy/paste-ready output only.
