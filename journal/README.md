# Cybersecurity Learning Journal

## Overview
Recruiter-facing index for cybersecurity learning notes, lab reflections, Bellevue coursework, and SOC analyst development artifacts.

## What I Did
- Organized learning notes and project reflections in one journal area.
- Captured coursework and lab context that supports the public portfolio.
- Kept deeper notes separate from polished project exports.
- Used the journal to track growth across SOC, blue team, and incident response topics.

## Key Findings
- The journal contains supporting learning material rather than a single finished lab.
- Bellevue coursework and SOC learning-path notes are kept in subfolders.
- The folder is useful as context, but individual polished projects should remain the primary recruiter-facing artifacts.

## Security Impact
Maintaining a learning journal helps show analyst growth, repeatable study habits, and reflection after technical work. For defenders, that habit matters because investigations improve when lessons learned are captured and reused.

## Tools Used
- Markdown
- Local portfolio notes
- Bellevue coursework notes
- SOC analyst learning materials

## Outcome
This folder acts as a supporting portfolio index for learning and reflection. It should stay concise and direct so recruiters can understand its purpose without mistaking it for a single technical lab.
