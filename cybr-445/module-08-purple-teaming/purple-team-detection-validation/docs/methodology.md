# Methodology

This project documents a public-safe summary of the purple-team validation workflow.

1. Performed controlled purple-team validation in a lab environment.
2. Used Atomic Red Team style tests for discovery and credential-access behavior.
3. Used Caldera for automated adversary-emulation style testing.
4. Reviewed detection output in Elastic/Kibana.
5. Documented test cases, outcomes, severity, and defensive mapping in VECTR.
6. Kept raw coursework artifacts local.

The goal was to validate defensive visibility without publishing private lab details, internal infrastructure, or coursework-only submission artifacts.
